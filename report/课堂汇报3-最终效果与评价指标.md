# 课堂汇报 3：最终效果与评价指标

## 1. 评价指标

本项目使用题目要求的 MAPE 作为评价指标：

```text
MAPE = average(|真实流量 - 预测流量| / 真实流量)
```

MAPE 越低，说明预测结果越接近真实值。

选择 MAPE 的意义是：

- 它衡量的是相对误差，便于比较不同收费站和不同时段。
- 对低流量窗口更敏感，因此能暴露小流量场景下的预测偏差。
- 与 KDD Cup 2017 该任务的评价方式一致。

代码中 MAPE 计算实现于 `src/utils.py` 的 `calculate_mape` 函数，并跳过真实流量为 0 的样本，避免除零问题。

## 2. 验证集设置

为了避免数据泄露，项目没有随机划分训练集和验证集，而是严格按照时间切分：

- 训练部分：2016-10-11 之前的数据。
- 验证部分：2016-10-11 至 2016-10-17。

验证集模拟真实预测方式：

- 只使用目标窗口之前的数据。
- 用 06:00-08:00 预测 08:00-10:00。
- 用 15:00-17:00 预测 17:00-19:00。

验证集共包含：

```text
7 天 * 2 个时段 * 6 个窗口 * 5 个组合 = 420 条样本
```

## 3. 模型效果对比

项目最终比较了四类模型结果：

| 模型 | 验证集 MAPE |
| --- | ---: |
| Ridge | 0.261726 |
| 统一 XGBoost | 0.169450 |
| Per-combo XGBoost | 0.148374 |
| Hybrid XGBoost | 0.145387 |

可以看到：

- Ridge 作为线性基线，MAPE 为 `0.261726`。
- 统一 XGBoost 明显优于 Ridge，说明非线性模型更适合当前表格特征。
- Per-combo XGBoost 进一步降低误差，说明不同收费站-方向组合存在明显差异。
- Hybrid XGBoost 在验证集上表现最好，最终 MAPE 为 `0.145387`。

因此项目最终选择：

```text
Hybrid XGBoost
```

作为提交预测方案。

## 4. 分组效果分析

按收费站-方向组合统计，最终 Hybrid XGBoost 的 MAPE 如下：

| 组合 | Hybrid XGBoost MAPE |
| --- | ---: |
| `1_0` | 0.187218 |
| `1_1` | 0.158991 |
| `2_0` | 0.140745 |
| `3_0` | 0.120196 |
| `3_1` | 0.119784 |

其中：

- `1_0` 是当前误差最高的组合，说明该方向流量波动更大或规律更复杂。
- `3_0` 和 `3_1` 误差较低，说明这两个组合的流量模式更稳定。

Hybrid 策略对不同组合选择不同模型：

| 组合 | 选择模型 |
| --- | --- |
| `1_0` | Per-combo XGBoost |
| `1_1` | 统一 XGBoost |
| `2_0` | Per-combo XGBoost |
| `3_0` | 统一 XGBoost |
| `3_1` | 统一 XGBoost |

这种方式兼顾了统一模型的泛化能力和分组模型的个性化拟合能力。

## 5. 早晚高峰效果

按时段统计：

| 时段 | Hybrid XGBoost MAPE |
| --- | ---: |
| 早高峰 | 0.133527 |
| 晚高峰 | 0.157246 |

结果显示：

- 早高峰预测效果更好。
- 晚高峰误差更高，可能与下班时间弹性、晚间活动、道路状态变化更复杂有关。

## 6. 预测步长效果

按未来第几个 20 分钟窗口统计：

| 预测步长 | Hybrid XGBoost MAPE |
| --- | ---: |
| 1 | 0.128705 |
| 2 | 0.138786 |
| 3 | 0.128138 |
| 4 | 0.146721 |
| 5 | 0.148217 |
| 6 | 0.181753 |

整体趋势是预测越靠后难度越大，尤其是第 6 个窗口误差最高。这符合交通预测的一般规律：距离当前时间越远，不确定性越高。

## 9. 本部分小结

最终模型在时间验证集上达到 `0.145387` 的 MAPE，相比 Ridge 基线明显提升。结果说明，短期流量、历史周期、时间、天气和路网特征的融合是有效的；同时，按收费站-方向组合进行模型选择，可以进一步改善整体预测效果。
