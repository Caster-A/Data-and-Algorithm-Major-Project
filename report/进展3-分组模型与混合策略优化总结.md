# 进展 3：分组模型与混合策略优化总结

## 1. 本阶段目标

进展 2 完成了历史周期统计特征增强，使统一 XGBoost 的验证集 MAPE 从 `0.172920` 降至 `0.169450`。

但评估结果仍显示不同收费站方向组合之间差异明显，尤其是：

```text
combo_id=1_0
```

仍然是误差最高的组合。

因此，进展 3 的目标是从统一模型进一步优化为：

```text
按 combo_id 分别训练模型，并在验证集上选择更优策略
```

## 2. 分支说明

本轮优化在新分支中进行：

```text
codex/per-combo-xgboost
```

这样可以保留原有稳定版本，同时单独验证分组建模策略是否有效。

## 3. 本次优化内容

主要修改文件：

```text
src/train_model.py
src/evaluate.py
report/模型评估摘要.md
```

新增了三类 XGBoost 预测结果：

### 3.1 统一 XGBoost

所有收费站方向组合共用一个 XGBoost 模型。

这是进展 2 的主模型。

### 3.2 Per-combo XGBoost

按照 `combo_id` 分组，为每个收费站方向组合分别训练一个 XGBoost 模型。

当前共有 5 个组合：

```text
1_0
1_1
2_0
3_0
3_1
```

这样做的原因是不同收费站方向组合的流量水平和波动模式差异较大，统一模型可能无法充分拟合每个组合的独立规律。

### 3.3 Hybrid XGBoost

Hybrid 策略在验证集上比较：

```text
统一 XGBoost
Per-combo XGBoost
```

对每个 `combo_id`，选择验证 MAPE 更低的模型用于该组合预测。

当前选择结果：

| combo_id | 选择模型 |
| --- | --- |
| `1_0` | per-combo XGBoost |
| `1_1` | 统一 XGBoost |
| `2_0` | per-combo XGBoost |
| `3_0` | 统一 XGBoost |
| `3_1` | 统一 XGBoost |

## 5. 优化结果

### 5.1 整体 MAPE 对比

| 模型 | 验证集 MAPE |
| --- | ---: |
| Ridge | 0.261726 |
| 统一 XGBoost | 0.169450 |
| Per-combo XGBoost | 0.148374 |
| Hybrid XGBoost | 0.145387 |

从结果看：

- Per-combo XGBoost 明显优于统一 XGBoost。
- Hybrid XGBoost 进一步略优于 per-combo XGBoost。
- 当前最佳模型为 `hybrid_xgboost`。

### 5.2 相对进展 2 的提升

## 6. 当前结论

本轮优化效果显著。

主要结论：

- 分组建模比统一建模更适合当前数据。
- `1_0` 和 `2_0` 适合使用 per-combo 模型。
- `1_1`、`3_0`、`3_1` 使用统一 XGBoost 更稳。
- Hybrid XGBoost 能结合两种模型优势，成为当前最佳方案。
- 当前整体 MAPE 已从第一版 XGBoost 的 `0.172920` 降至 `0.145387`。

## 7. 后续优化计划

下一步可以继续从以下方向优化：

### 7.1 参数调优

针对当前最佳的 Hybrid XGBoost，进行小范围参数搜索：

```text
n_estimators
max_depth
learning_rate
subsample
colsample_bytree
reg_lambda
```

调参时应继续使用时间验证集，不能随机切分。

### 7.2 加入更多模型对照

可以尝试：

```text
RandomForest
ExtraTrees
GBDT
```

并与 XGBoost 做验证集对比。

### 7.3 简单模型融合

如果 ExtraTrees 或 RandomForest 在部分组合上优于 XGBoost，可尝试：

```text
final_pred = w1 * xgboost_pred + w2 * extra_trees_pred
```

但必须基于验证集表现决定权重。

### 7.4 报告整理

本轮结果适合写入最终报告的模型优化章节：

- 统一模型作为 baseline。
- 历史周期特征作为第一次优化。
- Per-combo 和 Hybrid 作为第二次优化。
- 用 MAPE 表格说明优化效果。
