# 课堂汇报 4：代码讲解

## 1. 项目代码结构

项目主体代码位于 `src/` 目录，按数据处理流程拆分为四个核心脚本：

| 文件 | 功能 |
| --- | --- |
| `src/data_cleaning.py` | 数据读取、清洗、20 分钟窗口聚合、提交模板生成 |
| `src/feature_engineering.py` | 滑动窗口样本构造、历史/天气/路网特征融合 |
| `src/train_model.py` | 模型训练、验证集预测、模型选择、提交文件生成 |
| `src/evaluate.py` | 结果评估、分组指标统计、可视化图表和评估报告生成 |
| `src/utils.py` | 公共工具函数，主要是 MAPE 计算 |

推荐运行顺序为：

```bash
python src/data_cleaning.py
python src/feature_engineering.py
python src/train_model.py
python src/evaluate.py
```

## 2. 数据处理代码

数据处理主要在 `src/data_cleaning.py` 中实现。

### 2.1 读取原始数据

`read_volume()` 负责读取 volume 原始数据，并完成字段清洗：

- 统一字段名。
- 转换时间字段。
- 转换收费站和方向字段。
- 删除关键字段缺失记录。
- 过滤无关收费站-方向组合。

### 2.2 构造完整时间索引

`build_complete_index()` 生成完整的 20 分钟时间窗口和 5 个收费站-方向组合。

这样即使某些窗口没有车辆通过，也会在结果中保留一行，并将流量填为 0。

### 2.3 聚合 20 分钟流量

`aggregate_volume()` 将逐车记录聚合为：

```text
time_window_start + tollgate_id + direction -> volume
```

聚合后会调用 `add_time_features()` 添加时间字段。

### 2.4 异常值处理

`mark_and_smooth_outliers()` 使用箱线图规则标记异常值，并用过去窗口滚动中位数生成平滑流量列 `volume_smooth`。

这里的关键点是只用历史窗口，避免未来信息泄露。

### 2.5 提交模板

`build_prediction_template()` 生成 2016-10-18 至 2016-10-24 的目标预测窗口模板，共 420 行。

`save_outputs()` 是该脚本的主流程函数，负责保存：

- `data/processed/volume_train_20min.csv`
- `data/processed/volume_test_known_20min.csv`
- `data/processed/volume_observed_20min.csv`
- `data/submission/submission_template_phase1.csv`

## 3. 特征工程代码

特征工程主要在 `src/feature_engineering.py` 中实现。

### 3.1 滑动窗口样本

`build_session_samples()` 是特征工程的核心函数。

它按早高峰和晚高峰分别构造样本：

- 早高峰：用 06:00-08:00 预测 08:00-10:00。
- 晚高峰：用 15:00-17:00 预测 17:00-19:00。

函数会生成：

- 6 个滞后流量特征。
- 前 2 小时和前 1 小时统计特征。
- 预测步长 `horizon_step`。
- 早晚高峰标记和时间字段。

### 3.2 历史周期特征

`prepare_history_volume()` 整理历史流量表。

`add_historical_features()` 为每个预测样本补充历史统计特征，包括：

- 同组合历史均值。
- 同时间窗口历史均值。
- 同星期几、同时间窗口历史均值。
- 最近 3 天和 7 天同窗口均值。
- 前一天同窗口流量。

该函数对每个样本都限制历史数据时间必须早于目标窗口。

### 3.3 天气特征

`load_weather_features()` 读取训练和测试天气数据。

`merge_weather()` 用 `pd.merge_asof()` 为目标窗口匹配最近一次已知天气观测，并计算天气观测滞后时间。

### 3.4 路网拓扑特征

`build_route_features()` 读取 routes 和 links 表，将道路 link 的长度、宽度、车道数等属性聚合到收费站层面。

### 3.5 特征表输出

`finalize_features()` 融合静态路网特征，并生成：

- `combo_id`
- `session_id`

`save_feature_tables()` 保存最终特征表：

- `data/processed/train_features.csv`
- `data/processed/predict_features_phase1.csv`
- `data/processed/route_topology_features.csv`

## 4. 模型训练代码

模型训练主要在 `src/train_model.py` 中实现。

### 4.1 特征选择与时间切分

`select_feature_columns()` 选择数值型特征进入模型，并排除目标值、时间字符串等非训练字段。

`split_train_validation()` 按时间切分训练集和验证集：

- 训练集：2016-10-11 之前。
- 验证集：2016-10-11 至 2016-10-17。

这种切分方式符合真实预测场景。

### 4.2 模型构建

`build_ridge_model()` 构建 Ridge 线性基线模型。

`build_xgboost_model()` 构建 XGBoost 回归模型，使用较保守的参数：

- `max_depth=3`
- `learning_rate=0.05`
- `n_estimators=300`
- `subsample=0.85`
- `colsample_bytree=0.85`

### 4.3 分组模型与混合策略

`fit_predict_per_combo()` 按 `combo_id` 为 5 个收费站-方向组合分别训练 XGBoost。

`choose_combo_model_map()` 在验证集上比较统一 XGBoost 和 Per-combo XGBoost，为每个组合选择 MAPE 更低的模型。

`add_hybrid_predictions()` 和 `build_hybrid_submission_predictions()` 根据组合级选择结果生成 Hybrid XGBoost 预测。

最终选择整体验证 MAPE 最低的模型生成提交文件。

### 4.4 输出文件

`save_predictions_and_metrics()` 保存：

- `data/processed/validation_predictions.csv`
- `data/processed/model_metrics.csv`
- `data/submission/submission_phase1.csv`

## 5. 评估代码

评估主要在 `src/evaluate.py` 中实现。

### 5.1 提交文件检查

`validate_submission()` 检查提交结果是否满足题目要求：

- 字段正确。
- 行数正确。
- 无缺失预测值。
- 无负数预测值。
- 预测窗口与模板一致。

### 5.2 分组指标统计

`build_group_metrics()` 从多个维度统计 MAPE：

- 整体。
- 收费站-方向组合。
- 早晚高峰。
- 预测步长。
- 星期几。
- 是否周末。

输出文件为：

- `data/processed/evaluation_group_metrics.csv`

### 5.3 可视化图表

`save_figures()` 生成课堂汇报中可用的图表：

- 真实值与预测值散点图。
- 每日平均流量对比图。
- 按组合、时段、预测步长的 MAPE 柱状图。

图表保存在：

- `figures/`

### 5.4 评估摘要

`save_report()` 自动生成：

- `report/模型评估摘要.md`

其中记录了最终 MAPE、最佳模型、提交检查结果和主要误差来源。

## 6. 代码流程总结

项目代码整体流程可以概括为：

```text
原始逐车数据
-> 20 分钟窗口聚合
-> 异常值处理和时间字段补充
-> 构造滑动窗口监督学习样本
-> 融合历史、时间、天气、路网特征
-> 训练 Ridge / XGBoost / Per-combo XGBoost
-> 验证集选择 Hybrid XGBoost
-> 生成提交文件和评估报告
```

这套实现将课程要求的数据处理、特征提取、特征融合、模型预测和结果评估串成了完整闭环，最终能够稳定生成符合提交格式的预测结果。
